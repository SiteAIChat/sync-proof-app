# Sync proof app

A tiny Vite site that VibeControl uses to test its GitHub sync (versioned projects, Phase A).

- `main` is where work happens; `production` is what is live.
- Every push to `production` deploys it to GitHub Pages (`.github/workflows/deploy.yml`).
- `production` is updated with promote merges from `main`, so it holds merge commits that `main` does not.

It holds nothing secret. It is generated by `scripts/qa/versioned-workspaces/sync-proof-app.mjs` in the VibeControl repository.
